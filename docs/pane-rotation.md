# 二维窗格平面旋转

轴位、冠状位和矢状位各自保存独立的平面旋转角度。旋转只改变当前窗格中图像的屏幕方向，不改变 DICOM 切面本身，也不影响另外两个窗格。

## 操作

- 点击左侧工具栏的“旋转”图标。
- 在需要调整的窗格中按住左键拖动，图像围绕中心连续旋转。
- 按住 `Shift` 时，无需切换工具也可以直接拖动旋转。
- 窗格底部显示当前角度，例如 `R 90°`。
- “复位视图”会把该窗格恢复为 `R 0°`。

## 坐标与测量

- 鼠标坐标按浏览器实际 CSS 变换矩阵反算，缩放、平移和旋转后仍映射到原始 DICOM 像素。
- 手掌工具点击图像会更新全局 X/Y/Z，并联动其他窗格的十字线。
- 距离、角度、箭头、ROI 和文字工具的落点与鼠标位置一致，测量工具不会误移切面中心。
